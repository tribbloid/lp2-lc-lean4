## Overview

You job is to convert Coq proof for DOT (Scala's type system) into Scala examples and Lean4 proof.

You are in a very safe, sandboxed environment. You can use gradle & lake to compile code at will.

## Tasks (mark as complete when done)

- [ ] Explain/Demo Scala language features defined as types in [FsubL_alt.v](../../Lp2lc_coq/Active/FsubL_alt.v) using rule in [Demo.md](../Demo.md), write Scala code into [FsubL_alt.scala](../../example/src/main/scala/lp2lc/example/FsubL_alt.scala)
- [ ] Explain theorems in [FsubL_alt.v](../../Lp2lc_coq/Active/FsubL_alt.v) using rule in [Explain.md](../Explain.md), write Scala code & comment into [FsubL_alt_theorem.scala](../../example/src/main/scala/lp2lc/example/FsubL_alt_theorem.scala)
- [ ] Convert types & propositions in [FsubL_alt.v](../../Lp2lc_coq/Active/FsubL_alt.v) into [FsubL_alt.lean](../../Lp2lc/Active/FsubL_alt.lean) using rule in [Scaffold.md](../Scaffold.md),
- [ ] Discharge theorems in [FsubL_alt.lean](../../Lp2lc/Active/FsubL_alt.lean) using rule in [Discharge.md](../Discharge.md),
